BlindMaze

Round 1
Memorizing Time:
7s

Instructions

  1. Input your name and click start button.
  2. Use the memorizing time to memorize the way to finish.
  3. Use the arrow key to the finish square without hitting the wall.
  4. Hitting the wall or running out of time will decrease the number of lives.
  5. If you don't have lives left, game over.
